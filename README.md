# Chatbot-Konsultasi-Kesehatan
Chatbot Konsultasi Kesehatan adalah aplikasi berbasis web yang menyediakan layanan konsultasi kesehatan awal melalui percakapan interaktif. Chatbot ini membantu pengguna memperoleh informasi kesehatan dasar, mengenali gejala umum, serta memberikan saran awal sebelum melakukan konsultasi dengan tenaga medis profesional.
